# Código Roto

Aplicación Android tipo quiz para practicar Kotlin. Muestra fragmentos de código y el usuario elige qué imprimen o dónde está el error.

## Tecnologías

- Kotlin y Jetpack Compose (Material 3)
- Arquitectura MVVM (capas Presentation y Data)
- StateFlow para el estado de la UI
- DataStore para guardar los datos del usuario
- Preguntas base en un archivo JSON local

Sin APIs externas, sin Room y sin SQLite.
